This project contains scripts and tools for image analysis related to fluorescence microscopy of giant unilamellar vesicles.
It belongs to the publication:
Stephan et al. (2024) "Giant unilamellar vesicles as a cell-free platform to study selective bacteriophage binding and genome injection at the Gram-negative outer membrane"
<a href="(https://doi.org/10.1101/2024.08.19.608551 )"></a>
